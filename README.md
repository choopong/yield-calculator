# Yield Calculator

Calculate yield per year in percentage base on price, cost, and income per month.

## Prerequisite
- [mise](https://mise.jdx.dev/)

## Setup

Make sure to install dependencies:

```bash
mise install
yarn install
```

## Development Server

Start the development server on `http://localhost:3000`:

```bash
yarn dev
```

## Production

Build the application for production:

```bash
yarn build
```

Locally preview production build:

```bash
yarn preview
```
